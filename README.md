## ✨ Features & Architecture

- **3D Hero Experience ("The Journey of a Software Engineer")**:
  - Interactive stylized 3D character drop, ground impact shockwaves, and futuristic road walk sequence.
  - Built with `@react-three/fiber`, `@react-three/drei`, GSAP, and Framer Motion.
- **5 Playable Interactive Project Sandboxes**:
  - **Wellspring (2026)**: Live interactive BMI & daily calorie calculator + intelligent symptom triage engine (React + Spring Boot + MySQL).
  - **SpanStrike (2024)**: Interactive 3D Unreal Engine 5 physics cannon simulation with 60 FPS monitor.
  - **House Rent & Electricity Bill Calculator (2023)**: Live tiered power tariff slider and automated multi-tenant split bill calculator.
  - **FitNHeal (2025)**: Interactive workout routine planner and calorie burn estimator.
  - **Healthline Insights (2024)**: Holistic preventive wellness index analyzer.
- **Official Resume Viewer & PDF Downloader**:
  - 1-click printable modal with exact verified credentials (`BCA 80% TERF's Academy`, `HSC 71% Annai Matric`).
  - Direct PDF download (`/Deepak_N_Resume.pdf`).
- **Interactive Developer Terminal ("Deepak OS")**:
  - Full CLI emulator supporting `whoami`, `education`, `skills`, `projects`, `satya`, `resume`, `clear`.
- **Holographic Achievements Showcase**:

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Framer Motion, Lenis Smooth Scroll

- **Animation**: GSAP (GreenSock), ScrollTrigger
- **Build Tool**: Vite

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
# or
npx vite --port 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
```
